# NitroDeck site

Interactive static site for NitroDeck: feature map, architecture, playgrounds, get started, integrations and an end-to-end tour. Plain HTML, CSS and JS, no build step.

Live: https://ahmed-m-hussein.github.io/NitroDeck.io/

Preview locally: `python -m http.server 8765` in this folder.

The homepage (`index.html`) is a short overview. Every feature, with search, is on `features.html`. Media lives in `assets/media/`. The full written reference is in [docs/feature-guide.md](docs/feature-guide.md).

## Packs marketplace

Browse packs at `marketplace.html`. Packs are JSON files in `packs/`; `catalog.json` is generated by `node tools/build-catalog.mjs`. See [CONTRIBUTING.md](CONTRIBUTING.md) to submit one.
